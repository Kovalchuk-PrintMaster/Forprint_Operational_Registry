# Product / Service Reference Policy

Operational Registry may store product/service display names and future Library references.

Until Library canonical catalog is ready, Operational Registry may preserve:

```text
product_or_service_display_name
raw_product_or_service_name
library_product_id optional
library_service_id optional
library_material_id optional
resolution_status

Display name is not canonical truth.

Library remains owner of canonical product, service and material semantics.
