# Calculator Output Package Reference Policy

Operational Registry may store references to Calculator outputs.

Allowed references:

```text
calculator_output_package_id
calculator_calculation_id
calculator_quote_id
calculator_order_draft_id
calculator_line_ref
calculator_operation_ref

Operational Registry must not store or own:

Calculator formulas
pricing rules
calculation engine logic
final pricing authority

Calculator Engine remains owner of calculation package generation.
